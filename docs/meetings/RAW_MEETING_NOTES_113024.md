### Raw Notes
## Raw Notes / Things to Fix

### Spreadsheet:

1. Fix master spreadsheet to show shipping cost (for PBP) and shipping price (to client) -- add shipping cost column and rename shipping column. Fix shipping cost for Mi Eelo. This should then connect to the "Shipping Cost from Partner ($)" number under Tab 3 section "3. Order Settings".

### Tab 1 (Proposal Generator):

1. Add a search bar to the product catalog to reduce scroll time.

2. The "Products in Proposal" section under "Proposal Preview & Settings" allows users to adjust the Markup % to change the Client Price. It should also have an option to adjust the other way around - adjust the Client Price, changing the Markup %.

3.  In the "Step 1. Review Product Matches" section of "4. Generate Powerpoint Proposal", when a user selects "Change" to change a product -> slide match, we need to add a button to exit out of that change window (users get stuck in that window if they don't make a change).

4. Add rounding options: current is just "marketing rounding" from multiples of ten to 09; need to add options to round to the nearest multiple of .50 cents. This should default to selected.

### Tab 2: Client Order Form Generator

1. We need to investigate and discuss moving this to a Google-Form or other Cloud-based option that we can send to clients to have them fill-out. The current system feels clunky. We can discuss and brainstorm ideas. We will also need another form for dropshipping, which needs to be very clear about the costs of returned packages (clients are charged if addresses are wrong and FedEx needs to return the package). 

### Tab 3: Order & Client Info

1. In the "2. Current Order" stage we need to implement a few changes to the "Pricing Breakdown" table:

    Change A: Add "Units" column to the able (between "Per Unit" and "Total" columns).

    Change B: Split the "Total" column into "PBP Cost" and "Client Price" (structured more like a balance sheet) to eliminate confusion on what numbers add up to which total.  

    Change C: Add the Product Name to the top of the table like "Item: product x"

2. We also need to add some changes to the "4. Order Summary" table:
    
    Change A: The customization costs should show up below the products subtotal (show products then products subtotal, then customization then customization subtotal).

    Change B: Split the "Total" column into "PBP Cost" and "Client Price" (more like a balance sheet) to eliminate confusion on what numbers add up to which total. 

    Change C: Add the Product Name to the top of the table like "Product: product x"

3. Add a place to add "Estimated Sales Tax" to orders under "3. Order Settings". This may get more sophisticated as we move on, but for now, just allow users to input a number (like they can for shipping).

4. Add an option for "Kitting Pricing" to section "3. Order Settings" - the business offers a lot of gift sets, and there are additional costs of kitting (packaging gifts together). This should include options for PBP Costs and Client Pricing.

5. Fix UX for adding Order Notes - probably every order will have order notes. We need to make it clear that it's possible and easy to add order notes (right now, the function is just in a discrete dropdown under "Add Order Notes" in section 3).

### Tab 4:

### Saving Progress and Orders:

1. The UX for saving proposals doesn't make any sense. I think it should be in the side-bar (showing Saved Proposals), and the "Save Proposal" button should be at the bottom of the first tab, after a user goes through the whole proposal generation process. We should discuss this in detail before implementation.

2. We need to improve the saving orders UX. It's very, very important that users can save everything and not lose their progress. Most orders will likely not be totally completed in one session, so users must be able to save really easily. We need to discuss this.

3. Clicking "Clear Data" clears "Saved Orders". This is really misleading from a UX standpoint, and a huge error that could be really costly. We must be able to save proposals and orders across sessions.

4. Add "Net 15" option to payment terms, and a custom configuration.

5. Add ability to add multiple points of contact (i.e. Contact 1, Contact 2, etc.). Users should be able to add as many as they want.

### Tab 4:

1. Add functionality for users to change product descriptions ("Item + Specs" column) in the final step, since this info will go to a bookkeeper then clients, and we need better descriptions than (for example) "LAVENDER SHORTBREAD MIX No Tiers"
