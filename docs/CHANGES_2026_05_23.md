# Changes & Bug Fixes — May 23, 2026

1. Added a "Current Proposal" sidebar widget that shows all products in the proposal (most recently added first) with a scrollable list and a dropdown to remove products, so users don't have to scroll through 200+ products to see what's in their proposal.
2. Simplified the "Save Proposal" section in Tab 2 by removing the duplicate "Load Proposal" UI (loading is now only done from the sidebar) and keeping just the save fields inline without an expander.
3. Cleaned up the Data Status sidebar section: removed the debug data details dropdown, hid the refresh button behind a "Having data issues?" expander so it's not confusing but still available if needed.
4. Removed the duplicate "Client Budget" input from Proposal Settings since it's already set at the top when filtering products.
5. Fixed the Client Budget Range filter to use MSRP when available instead of always using cost x2, and added a transparency message showing how many products are filtered by MSRP vs estimated price.
6. Added a "Clear All Filters" button that resets all filters (budget range, partner, country, search) back to defaults with one click.
7. Replaced the "Generate Proposal Tables" section with a discreet "View raw proposal data (debug)" expander, and removed the CSV download option since proposals are now generated as PowerPoints.
8. Fixed slide matching so it finds slides even when the title isn't in the first shape -- now checks the PowerPoint title placeholder first, then all shapes on the slide, instead of only looking at shapes[0].
9. Replaced the non-functional "Continue to next tab" buttons at the bottom of Tabs 1, 2, and 3 with a simple text note telling users to scroll up and select the next tab.
10. Changed Google Form URL generation from auto-generated to on-demand: added a "Generate Form URL" / "Update Form URL" button so users can regenerate the URL after making changes to client info or products.
11. Promoted "Import from Proposal (Tab 1)" from a hidden expander to its own full section (Option B) in Tab 3, since it's the most commonly used workflow. Renamed Manual Product Selection from Option B to Option C.
12. Added "PBP In-Hands Date" field — the date PBP needs to receive product from the partner. Added as an input in both Tab 3 (Section 5) and Tab 4 (Client & Order Information), and displayed in the Order Details table and HTML export for Purchase Orders.
13. Added editable "Customization Description" field for base customization in Tab 3. Pre-fills from spreadsheet data if available, and shows on the pricing breakdown table and invoice/PO line items so clients can see exactly what they're being charged for.
14. Fixed HTML/CSV download buttons serving stale data in Tab 4. The download buttons now use dynamic keys that change when the invoice content changes, so the downloaded file always matches what's shown on screen.
15. Hid the Shipping & Tariffs section behind a "Legacy" expander in both Tab 3 (Order Settings) and Tab 4 (Edit Order Settings), since shipping and tariff costs are now factored into product pricing in the spreadsheet. The functionality is preserved but collapsed by default.
16. Added Product Photos section (Section 5) in Tab 3 — upload multiple photos (PNG, JPG, GIF, WEBP) related to an order. Photos display as thumbnails in a grid and are embedded in the HTML invoice/PO download in Tab 4. Session-only storage (photos don't persist after closing the app).
17. Upgraded Product Photos to per-product storage with cross-session persistence. Photos are now uploaded per product (dropdown selector, up to 5 per product, thumbnail grid with summary). Photos are saved to Google Sheets as base64 chunks when the order is saved, and restored when the order is loaded. Tab 4 shows per-product photos with individual download buttons below the Invoice/PO download section. Photos are automatically cleaned up when an order is deleted.
